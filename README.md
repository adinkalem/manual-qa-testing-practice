# 🧪 Manual QA Testing Practice Project

## 📌 Overview  
This repository contains my **first manual QA testing project**. I am new to software testing, and this is my initial hands-on experience with QA processes and documentation.

For this project, I used a real website provided by a friend: **Avdoh2160.com**.  
The goal was to explore the application, create test cases, and identify potential issues in functionality and user experience.

---

## 🎯 Objectives  
- Learn the basics of manual QA testing  
- Practice writing test cases  
- Identify and document bugs  
- Understand how to structure QA documentation  

---

## 🔍 Scope of Testing  
Testing was focused on core functionalities of the web application, including:  
- Page navigation  
- User registration and login  
- Basic form validation  
- General usability  

---

## 📂 Test Documentation  
This project includes the following QA artifacts:

- 📄 **Test Plan** – Overview of testing strategy and scope  
- 📊 **Test Cases** – Defined scenarios and expected results  
- 🐞 **Bug Report** – Documented issues found during testing  
- 📈 **Test Summary** – Final overview of testing results  
- 💡 **Improvements & Suggestions** – Recommendations for enhancing the application  

---

## ⚠️ Findings  
During testing, several issues and usability problems were identified.  
These include:
- Inconsistent language usage across the application  
- Lack of input guidance (email & password fields)  
- Limited visibility of membership information for non-logged-in users  

All identified issues are documented in the **Bug Report**, along with suggested improvements.
